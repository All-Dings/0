# Dings-Mac-Win-Germany.keylayout

I am a [Config-File](9000007.md) for [MacOS](9000143.md) to enable a [Keyboard-Layout](700017.md) for [Windows](9100002.md).

## Installation

Download Config-File: [win-germany.keylayout](300030008.keylayout).

```bash
$ cp 300030008.keylayout ~/Library/Keyboard\ Layouts/win-germany.keylayout
```

Then open "Apple >> Systemeinstellungen >> Hardware >> Tastatur", then go to "Texteingabe >> Eingabequellen >> Bearbeiten", use "+" and select "Andere".
