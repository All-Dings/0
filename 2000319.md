# Unified-Diff-File

I am a [File](9000007.md), that stores a Unified-Patch in Unified-Diff-Text Format.

## Description

I describe Changes between a Source-Payload and a Target-Payload in a line-oriented textual Patch Format.

I can be imported and exported by [Dings_App_Unified_Diff](300042011.dmd).

Inside Dings-SM, my canonical Meaning is [Dings_SM_Patch](300043939.md).
